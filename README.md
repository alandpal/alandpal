¡Hola! Soy Albert 👋

Explorando el mundo del Data Science y el Análisis de Datos

Bienvenido a mi repositorio. Aquí documento mi camino hacia el análisis de datos avanzado, impulsado por la curiosidad de ir más allá del análisis superficial y extraer valor real de los datos.

Mi formación en Economía me aporta una base sólida para entender el contexto de negocio y plantear las preguntas correctas. He complementado esta visión analítica con el dominio de herramientas técnicas como Python, SQL y Machine Learning, lo que me permite abordar problemas complejos con mayor profundidad y eficacia.

Este repositorio es mi espacio de trabajo donde encontrarás los proyectos desarrollados durante mi formación, así como futuros experimentos y análisis que iré publicando para seguir creciendo en el mundo de los datos.
